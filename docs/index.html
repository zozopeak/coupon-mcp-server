ZoZoPeak Coupon MCP Server

A free remote MCP server that gives AI assistants coupon codes and current deals for online stores. There is nothing to install: your assistant connects to one server URL over Streamable HTTP, with no API key and no account. Offers are gathered from official store and affiliate-program feeds.

The one thing you need

The server URL you paste into any MCP client:

https://mcp.zozopeak.com/mcp

Quick start

  1. Open the connector or MCP settings of your assistant (Claude, ChatGPT, Cursor, VS Code, or another MCP client).
  2. Add a custom remote connector and paste the server URL above. Choose the option with no sign-in.
  3. Enable the connector in a chat and ask for coupons by store name.

Client-by-client walkthroughs with copy-ready configuration live on the install page.

What your assistant can ask for

Two read-only tools come with the server. See the tool reference for parameters and reply shapes.

ToolWhat it returns
find_couponsCoupon codes for the store you name, with titles and stated discounts.
find_store_dealsDeal links for the store you name, with titles and stated discounts.

Try these prompts

  • "Find coupon codes for AliExpress."
  • "Find coupon codes for Noon in the UAE."
  • "Find deal links for Amazon in the US."
  • "Show me current deals for SHEIN."
  • "Find coupons for Amazon and show the ones with the biggest stated saving."
