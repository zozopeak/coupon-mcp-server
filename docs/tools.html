Tool Reference: find_coupons & find_store_deals

The server exposes two read-only tools. Each works on one store per call: the assistant names a store, the tools look up what is listed for it in official store and affiliate-program feeds, and the result comes back as structured text your assistant can read out. Neither tool writes anything anywhere.

Shared parameters

ParameterTypeRequiredMeaning
storestringyesThe store to look up. Use the name shoppers actually use, for example "amazon" or "noon". Spelling matters.
countrystringnoA country or region name. When given, results are matched to that market.
limitintegernoThe most rows to return. When omitted, the server picks a sensible count on its own.

Both tools accept exactly these three parameters and no others.

find_coupons

Returns coupon codes for the named store. Codes are shown exactly as they appear in the feeds; each row also carries the offer title, the discount as stated by the feed, and a link that opens the offer at the store.

Example prompt: "Find coupon codes for Noon in the UAE." — this calls find_coupons with store: "Noon" and country: "UAE". The reply lists rows of this shape:

{
  "store": "STORE NAME",
  "code": "CODE123",
  "title": "OFFER TITLE",
  "discount": "XX% OFF",
  "link": "a link to the offer at the store",
  "last_seen": "DATE the feed listed this offer"
}

find_store_deals

Returns deal links for the named store: offers reachable without a code. Each row carries the offer title, the stated discount and the link.

Example prompt: "Find deal links for Amazon in the US." — this calls find_store_deals with store: "Amazon" and country: "US". The reply lists rows of this shape:

{
  "store": "STORE NAME",
  "title": "OFFER TITLE",
  "discount": "XX% OFF",
  "link": "a link to the offer at the store",
  "last_seen": "DATE the feed listed this offer"
}

Every link in a reply opens over https. When a reply contains links, it also carries a short line noting that ZoZoPeak may earn a commission on them.

Prompts that work well

  • "Find coupon codes for AliExpress."
  • "Find coupon codes for Noon in the UAE."
  • "Find deal links for Amazon in the US."
  • "Find coupons for Amazon and show the ones with the biggest stated saving."

The tools take one store per call. For two stores, ask for them one after the other; your assistant will call the tool twice.

Troubleshooting

Empty results for a store

Check the spelling first — the tools match the name you give. Try the store's common short name, or drop the country parameter to widen the match. A store with nothing listed in the feeds right now returns no rows; that is a plain "no offers listed", not a failure.

Results without codes

Use find_coupons when you want codes and find_store_deals when you want links without codes. If a coupon row comes back with a discount but no code, the feed listed the offer without a code — the deal link is then the way in.

Old dates in last_seen

last_seen records when a feed listed the offer; it is a feed timestamp, not a statement that anyone used the code. Treat a much older date as a hint to prefer rows seen more recently.
