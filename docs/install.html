Connect the ZoZoPeak Coupon MCP

Everything your client needs is the server URL. It speaks Streamable HTTP, needs no authentication and is free to use. Wherever a step says "the server URL", paste this:

https://mcp.zozopeak.com/mcp

Claude (web and desktop)

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it ZoZoPeak and paste the server URL.
  4. Pick the choice that connects without signing in, then save.
  5. Start a chat, open the tools or connectors picker and switch ZoZoPeak on.
  6. Ask for coupons by store, for example: "Find coupon codes for Noon."

Claude Code

Run this once in your terminal; it registers the server for you:

claude mcp add --transport http zozopeak https://mcp.zozopeak.com/mcp

ChatGPT

  1. Open Settings → Connectors and start creating a custom connector.
  2. Give it a name, paste the server URL as the MCP server address, and choose the option with no authentication.
  3. In a chat, enable the connector from the tools or connectors picker.
  4. Ask for coupons or deals by store name.

Cursor

Two ways, both end at the same place:

  1. Open Cursor Settings → Tools & MCP, add a new MCP server, give it the name zozopeak and paste the server URL; or
  2. edit mcp.json and add the block below. The copy-ready file is examples/cursor-mcp.json in this repository.
{
  "mcpServers": {
    "zozopeak": {
      "url": "https://mcp.zozopeak.com/mcp"
    }
  }
}

VS Code

  1. Open the Command Palette and run MCP: Add Server.
  2. Choose HTTP as the type, name it zozopeak, and paste the server URL.
  3. Or save the block below as .vscode/mcp.json in your workspace (the copy-ready file is examples/vscode-mcp.json).
{
  "servers": {
    "zozopeak": {
      "type": "http",
      "url": "https://mcp.zozopeak.com/mcp"
    }
  }
}

Other clients (stdio only)

Clients that only launch local programs can reach the server through the mcp-remote bridge. Add this to your client's configuration (copy-ready file: examples/stdio-mcp-remote.json):

{
  "mcpServers": {
    "zozopeak": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.zozopeak.com/mcp"]
    }
  }
}

Node.js must be on your PATH for this variant, since npx runs the bridge locally.

Troubleshooting

The tools never appear

Confirm the connector is switched on for the chat you are in — many clients enable connectors per chat, not globally. Restart the client after editing a configuration file, then ask the assistant to list its available tools.

The connection fails

Check the URL character by character; it must be exactly the server URL shown at the top. When your client asks how to sign in, pick the no-authentication option — the server does not use accounts. Network filters that block unknown domains can also stop the connection; try a different network if one is available.

Free plans

Entry-level plans of some assistants allow only a small number of custom connectors. If yours is full, remove an unused connector first and then add ZoZoPeak.
